# Security Policy — Mechatronopolis

## Reporting a Vulnerability

If you identify a security issue in this repository, report it privately to the maintainers and do not disclose it publicly until remediated.

## Security Standards

- Never commit secrets, credentials, or tokens.
- Validate and sanitize all external inputs for any future app/API modules.
- Keep dependencies updated when code modules are introduced.
- Apply least-privilege access for deployment and infrastructure tooling.
